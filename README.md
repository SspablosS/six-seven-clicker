# Церковь Шесть-Семь — кликер-тайкун

Мемный кликер про культ вокруг фразы «6-7».

## Запуск

```bash
npm run install:all
npm run dev
```

- **Клиент:** http://localhost:5173
- **Сервер:** http://localhost:3001
- Запросы с клиента на `/api/*` проксируются на сервер через Vite.

## Структура

```
client/   — React (Vite)
server/   — Express API
config/   — баланс и формулы (gameConfig.js)
```

## Данные

Сохранения игроков: `server/data/saves.json` (создаётся при первом запуске сервера).

**Зона роста:** запись в JSON сейчас через простую очередь в памяти. При параллельных инстансах сервера нужен lock-файл или настоящая БД.

## Монетизация (мок, без реальных платежей)

Все элементы в UI-блоке **«Магазин культа»** (`client/src/MonetizationPanel.jsx`), константы — `config/gameConfig.js` → `MONETIZATION` / `AD_BOOST`.

| Идея | Что в UI | Как зарабатывало бы в проде |
|------|----------|-----------------------------|
| Абонемент «Проповедник» | Баннер с ценой и списком бонусов → модалка «Скоро!» | Подписка (Store / Stripe), recurring revenue |
| Скины мегафона | Галерея, «покупка» только меняет цвет кнопки | IAP косметики, без pay-to-win |
| Реклама ×2 на 5 мин | Таймер «рекламы» 3 сек → реальный буст дохода | Rewarded video (AdMob и т.п.) |
| «Без рекламы» | Кнопка с ценой → заглушка | Разовый IAP remove-ads |

Подробное описание игры и экономики — в финальном README (эпик E9).
